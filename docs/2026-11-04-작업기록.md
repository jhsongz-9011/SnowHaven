# 2026-11-04 작업 기록 — 캐릭터 모델 적용 + 환경 효과

## 요약
Blender 로 만든 캐릭터 3종(스키/보드/썰매)을 타는 자세·리프트 착석 자세로 만들어 GLB 로 내보내고,
게임의 박스 라이더를 교체했다. 이어서 눈가루·내리는 눈·활강 자국 효과와 리프트 배경 동승자 교체까지 진행.

## 1. 캐릭터 모델 (Blender, Blender MCP 사용)
- 디자인 시트 기반 캐릭터 3종: 보드(검정 모자·보라 고글), 스키(크림 모자·파랑 고글), 썰매(빨간 모자·목도리)
- 타는 자세 3종(역동적 기울임) + 리프트 착석 자세 3종
- 모자를 올려 이마가 보이게 수정
- 고글: 타는 자세에서 착용(썰매는 제외), 디자인을 곡면 미러 렌즈·프레임·스트랩·금속 배지로 고급화
- 폴리 수: 약 2.5~3.1k / 모델 (멀티플레이어 20명 기준 약 60k, 웹에서 부담 적음). 목표 2k 보다 높지만 형태 유지를 우선
- 서 있는 모델은 4k 안팎이라 내보내지 않음

## 2. 게임 적용
- `public/models/rider_{board,ski,sled}_{ride,lift}.glb` 6개 (각 130~150KB), 원본 `assets/characters.blend`
- `src/rider.ts`: GLTFLoader 로 로드. 로딩 중엔 비워 두고(깜빡임 방지), 실패하면 기존 박스 모델 사용
  - 조정값: `MODEL_SCALE`(1.25), `SEAT_OFFSET`(리프트 좌석 위치)
- `src/lift-view.ts`: 리프트의 배경 동승자를 GLB 로 교체 (장비 3종 × 인스턴싱, 정점 색 병합 지오메트리)
- 리프트 스키 모델에서 스키 폴 제거

## 3. 환경 효과
- `src/snow-fx.ts`: 활강 중 눈가루(속도·턴에 비례, 충돌 시 폭발). 조정값 `SNOW_FX`
- `src/env-fx.ts`: 내리는 눈(`Snowfall`, 둥근 점, 크기 제한) + 활강 자국(`SkiTracks`, 장비별 모양). 조정값 `ENV_FX`

## 4. 검증
- `npm run build`, `npm run simtest` 통과
- 헤드리스 Playwright 로 리프트 탑승 → 하차 → 활강 → 완주 흐름과 장비 3종 스크린샷 확인

## 5. 코드 리뷰 (서브에이전트) 와 수정
오늘 변경분(`203648d..5b930a4`)을 읽기 전용 서브에이전트로 리뷰하고, 코드에서 확인된 항목만 수정했다.
- 활강 자국: 샘플마다 전체 재계산·객체 생성 → 정점/높이를 샘플당 1회 계산, 바뀐 범위만 업로드. 장비를 바꿔도 기존 자국 유지, 페이드를 고정 길이로
- 드로우콜: 라이더 1명 약 40개 → 로드 시 같은 재질끼리 병합 (`mergeByMaterial`)
- 리프트 동승자: 병합 실패 시 씬에 찌꺼기가 남던 문제 수정(전부 만든 뒤 한 번에 부착), 프레임당 객체 생성 제거, 안 보이는 박스 모델 갱신 중단
- 눈가루: 프레임당 객체 생성 제거, 입자 없으면 갱신 생략, 넘어졌을 때 발생량을 시간 기준으로, 점 최대 크기 제한, 상수를 `SNOW_FX`로 모음
- GLB 로드 실패는 캐시하지 않아 재시도 가능
- 손대지 않음: 동승자 옷 색 변화(장비별 고정 색), 눈송이 셰이더 이동, 해상도별 점 크기 환산

## 6. 알려진 한계 / 다음 후보
- 활강 자국은 실제 플레이로 진하기 확인 필요 (`ENV_FX`, `env-fx.ts` 색)
- 배경 동승자는 장비별 고정 색 (옷 색 변형 없음)
- Blender 쪽 리프트 자세는 키 입력 기반 간이 IK 라 다리 모양이 단순함
